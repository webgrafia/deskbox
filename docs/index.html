Caratteristiche Principali

Progettato per chi esige ordine, velocità e zero distrazioni.

🔑

Google Session Bridge

Bypassa l'errore "Browser non sicuro" imposto da Google negli ambienti Electron attraverso un pratico wizard di sincronizzazione con Firefox. Login unificato per tutte le Google Apps.

🔔

Badge Numerici Intelligenti

Contatori delle notifiche precisi e puliti sia sulle schede laterali che nell'icona nella barra di sistema (System Tray), per non perdere mai una mail o un messaggio urgente.

🌐

Apertura Link nel Browser

Tutti i link esterni cliccati nelle tue email o nei messaggi di chat vengono aperti automaticamente nel tuo browser predefinito di sistema (Chrome, Firefox, Brave, ecc.).

🧮

Mini Calcolatrice Integrata

Fai calcoli al volo senza dover aprire app separate o calcolatrici esterne. Sempre a portata di clic con un'interfaccia a cassetto pulita e funzionale.

⚙️

Totale Personalizzazione

Attiva o disattiva i servizi, riordinali con semplici frecce Su/Giù e aggiungi qualsiasi web app aziendale o personale (Slack, Notion, Discord, ecc.).

🍏

Pronto per Linux & macOS

Eseguibile come app desktop nativa su Ubuntu, Debian, Fedora e su macOS sia con processori Intel che con i moderni chip Apple Silicon (M1, M2, M3, M4).

Installazione Rapida

Scegli la tua piattaforma preferita e inizia a usare Deskbox in 2 minuti.

Clona il repository ed esegui lo script di installazione per integrare Deskbox nel menù applicazioni di Ubuntu:

# 1. Clona il repository git clone https://github.com/webgrafia/deskbox.git cd deskbox # 2. Installa le dipendenze npm install # 3. Integra nel launcher desktop di Ubuntu con l'icona ufficiale ./scripts/install-desktop.sh # 4. Avvia Deskbox npm start

Puoi compilare direttamente il pacchetto nativo per macOS o scaricare lo ZIP generato:

# Compila pacchetto per Apple Silicon (M1/M2/M3/M4): npx electron-builder --mac zip --arm64 # Compila pacchetto per Mac Intel: npx electron-builder --mac zip --x64 # Installazione per utente Mac: 1. Estrai lo ZIP per ottenere Deskbox.app 2. Trascina Deskbox.app nella cartella Applicazioni 3. Al primo avvio: tasto destro sull'icona -> Apri (oppure Impostazioni -> Privacy e sicurezza -> Apri comunque)
